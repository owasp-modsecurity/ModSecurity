### Breaking changes

Deprecation of the `ubuntu-22.04` and `ubuntu-22.04-arm` runner images.
Brownouts: March 23, 14:00 UTC and April 13, 14:00 UTC.

### Target date

Deprecation: September 17th, 2026
Retirement: April 17th, 2027

### Runner images affected

- [x] Ubuntu 22.04
- [x] Ubuntu 22.04 Arm64
- [ ] Ubuntu 24.04
- [ ] Ubuntu 26.04

### Mitigation ways

Use `ubuntu-24.04` or `ubuntu-26.04` instead.
