### Breaking changes

Deprecation of Windows Server 2019 runner images.

### Target date

Final retirement date:
2025-06-30

### Possible impact

The `windows-2019` label will stop running.

### Runner images affected

- [x] Windows Server 2019
- [ ] Windows Server 2022

### Mitigation ways

Use `windows-2022` or `windows-2025` instead.
