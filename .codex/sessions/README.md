# Sitzungsprotokolle

Hier können abgeschlossene Arbeitssitzungen anhand von
[HANDOFF_TEMPLATE.md](../HANDOFF_TEMPLATE.md) dokumentiert werden.
Empfohlener Dateiname: Datum plus kurzer Aufgabenname, beispielsweise
`2026-10-25-kontextgrundlage.md`.

Ein Dateiname oder Beispiel behauptet keine bereits erfolgte Sitzung.
Die tatsächlich erstellte Ausgangsarbeit steht in
[CURRENT_STATE.md](../CURRENT_STATE.md).

Protokolle enthalten nur prüfbare Ergebnisse und für die Fortsetzung benötigten
Kontext. Zugangsdaten, private HTTP-Anfragen und vollständige sensible Logs
gehören nicht in diese versionierte Ablage.
